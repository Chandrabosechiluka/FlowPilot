# T-1049: Booking failed with 'conflict' but the appointment exists

## Symptoms
Advisor clicked Book, the screen froze, clicked again and got a Conflict error. The appointment appears once in the list.

## Investigation
Logs for the two correlation IDs: the first POST returned 201, the second 409 two seconds later for the same technician and time.

## Root cause
Double submission; the second request correctly lost to the first.

## Resolution
No data problem. Front-end team disabled the Book button while a request is in flight.
