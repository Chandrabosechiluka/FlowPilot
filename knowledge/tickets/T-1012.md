# T-1012: No-show list not updating since the morning

## Symptoms
Front desk at the Kukatpally shop: customers who never came are still shown as Booked at 1 pm. Yesterday they turned into no-shows by themselves.

## Investigation
Health checks were fine. API logs showed `Maintenance job 'no-shows' failed; it will be retried at the next run.` every minute since 09:40, with `SqlException: Execution Timeout Expired`. `sp_who2` on SQL Server showed a session from the owner's Excel report holding locks on `Appointments` since 09:38.

## Root cause
A reporting query from Excel (opened with a long-running transaction) blocked the maintenance job's update on the Appointments table.

## Resolution
With the owner's agreement the blocking session was ended. An Admin ran `POST /api/maintenance/run` (approved by the support lead): 14 appointments marked NoShow, 3 waitlist offers expired. Advised the owner to use the read-only report login, which reads without holding locks.
