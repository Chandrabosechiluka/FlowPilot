# T-1025: Customer booked at 3:30 am from the website

## Symptoms
A booking made on the shop's website widget for 9:00 am shows in GarageFlow at 3:30 am.

## Investigation
9:00 IST is 03:30 UTC. The widget converted correctly to `03:30Z`, then converted that UTC time again as if it were local, sending `22:00Z` of the previous day, which GarageFlow shows as 03:30 IST. API logs for the widget's correlation IDs confirmed the times it sent.

## Root cause
Website widget converted local time to UTC twice before calling the API.

## Resolution
Widget fixed to send only the `startUtc` returned by availability. Affected appointments (6) rescheduled with the customers' agreement.
