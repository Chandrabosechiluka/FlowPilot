# T-1037: Duplicate customers after importing from the old system

## Symptoms
After the shop's first data import, some customers appear twice, for example 'RAVI KUMAR' and 'Ravi Kumar'.

## Investigation
The first import was done with a spreadsheet macro, not FlowPilot's migration tool. It compared emails case-sensitively, so `RAVI.KUMAR@EXAMPLE.COM` and `ravi.kumar@example.com` became two customers before GarageFlow's lower-casing.

## Root cause
Case-sensitive duplicate check in an ad-hoc import script.

## Resolution
Merged the duplicates manually (6 pairs). Future imports use `flowpilot-migrate`, which compares emails in lower case and links existing customers instead of creating new ones.
