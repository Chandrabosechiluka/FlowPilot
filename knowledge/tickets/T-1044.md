# T-1044: Whole system down, 500 errors on every screen

## Symptoms
No screen works at the Miyapur shop's self-hosted GarageFlow; every action shows an error.

## Investigation
`/health` was 200 but `/health/db` was 503. `docker ps` showed the SQL Server container restarting. Its logs said the disk was full: Docker Desktop's virtual disk had grown to the drive's limit because old images were never cleaned.

## Root cause
Host disk full; SQL Server could not start.

## Resolution
Removed unused images (`docker image prune`), restarted SQL Server, then the API. Recovered in 25 minutes, no data lost. Added a monthly clean-up to the shop's checklist.
